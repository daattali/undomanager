# undomanager 0.2.0 (2026-11-01)

- Added `run_example()`, which launches a demo Shiny app (a pixel art editor with undo/redo history).
- `print()` gains an `n` argument to limit how many undo items and redo items are shown (the ones closest to the current item). By default all of them are still shown.
